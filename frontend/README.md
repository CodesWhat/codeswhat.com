# CodesWhat frontend

The Next.js app for the CodesWhat site.

- Setup and checks: [../README.md](../README.md#development)
- Deploy and configuration: [README-VERCEL.md](README-VERCEL.md)

The homepage is `app/(site)/page.tsx` and the fonts are in `app/fonts.ts`. Browser tests run against a production build, so run `npm run build:test` first.
