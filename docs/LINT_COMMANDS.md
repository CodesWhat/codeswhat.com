# Linting & Code Quality Commands

## 🚀 Quick Commands

### Run Everything at Once

```bash
npm run check      # ESLint + TypeScript checking
npm run check:all  # ESLint + TypeScript + Prettier
```

## 📋 Individual Commands

### ESLint

```bash
npm run lint       # Check for linting errors
npm run lint:fix   # Auto-fix linting errors
```

### TypeScript

```bash
npm run type-check # Check for type errors
```

### Prettier

```bash
npm run format       # Format all files
npm run format:check # Check if files need formatting
```

## 🎯 Common Workflows

### Before Committing

```bash
npm run check:all
```

### Fix All Issues

```bash
npm run lint:fix && npm run format
```

### Quick Check

```bash
npm run check
```

## 📝 Configuration Files

- `.eslintrc.json` - ESLint rules (auto-generated by Next.js)
- `.prettierrc` - Prettier formatting rules
- `.prettierignore` - Files to skip formatting
- `tsconfig.json` - TypeScript configuration

## 💡 VS Code Integration

Add these to your VS Code settings for auto-formatting:

```json
{
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  }
}
```
